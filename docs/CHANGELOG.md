# HeliAlert 버전 히스토리

버전 형식: **대규모.중규모.소규모**
- 대규모: 시스템 구조/인증 방식 등 근본적인 변경
- 중규모: 눈에 띄는 기능 추가·삭제, UI 구조 개편
- 소규모: 버그 수정, 작은 개선, 설정 변경

## v3.0.1 (소규모)
- GPS 세션 잠금 소유자(uid)가 설정되지 않던 문제 수정 (다른 조종사 사용 중 시작 차단, 하트비트 유지, 종료 시 잠금 해제)
- 잠금 획득을 트랜잭션으로 처리하고 잠금 문서의 이메일 표시를 로그인 계정으로 수정
- 감지 중지 직후 자동 재개되던 경합 방지

## v3.0.0 (대규모)
- 계정 관리 화면 추가 (알림설정 탭, 관리자 전용): 계정 생성, 역할 변경, 비밀번호 초기화, 정지/활성화, 삭제
- 역할 판별을 이메일 하드코딩에서 서버 claims(admin/pilot/crew) 기반으로 전환 (claims 없을 때만 임시 폴백)
- 관리자(admin)도 조종사 기능(GPS 감지) 사용 가능

## v2.3.1 (소규모)
- 지도 탭의 속도 표시를 KTS(노트)와 km/h 병기로 변경

## v2.3.0 (중규모)
- 이착륙 이벤트 기록을 계정별 저장 → 전체 공유 저장으로 전환 (크루도 조종사 이벤트 확인 가능)

## v2.2.1 ~ v2.2.5 (소규모)
- 헤더에 수동 새로고침 버튼 추가
- 서비스워커 캐시 전략 개선 (네트워크 우선)
- Google Maps API 키 교체 (결제 활성화 키로)
- GPS 정확도 기준 미달 시 15초 후 자동 진행 (무한 대기 방지)
- 지도 탭에 실시간 비행시간 표시 추가

## v2.2.0 (중규모)
- 운항 지점 설정 기능 삭제 (반경 밖 이벤트 무시 → 알림 누락 위험 제거, 시스템 단순화)

## v2.1.0 (중규모)
- 위치확인 버튼, 헤더 GPS 버튼 삭제
- 하단 탭바로 UI 개편 (모바일 엄지 조작 최적화)
- 세이프에어리어(노치) 대응, 당겨서 새로고침 방지

## v2.0.0 (대규모)
- 익명 인증 → 이메일/비밀번호 로그인 시스템 전환
- pilot / crew 권한 분리
- GPS 세션 중복 사용 방지 (한 번에 한 명만 감지 가능)
- 헬기 마커 진행 방향 자동 전환, 저수지 라벨 숨김, Wake Lock 재요청 버그 수정

## v1.1.0 (기준점)
- 헬기 마커 색상 커스텀
- 항적(비행 경로) 24시간 자동 만료 처리
