# HeliAlert 버전 히스토리

버전 형식: **대규모.중규모.소규모**
- 대규모: 시스템 구조/인증 방식 등 근본적인 변경
- 중규모: 눈에 띄는 기능 추가·삭제, UI 구조 개편
- 소규모: 버그 수정, 작은 개선, 설정 변경

## v2.3.1 (소규모)
- 이벤트 자동 만료 기간 3일 → 2일로 단축
- 이벤트 로그에 수동 삭제 버튼 추가 (확인 후 삭제)

## v2.3.0 (중규모)
- 이착륙 이벤트 기록을 계정별 저장 → 전체 공유 저장으로 전환 (크루도 조종사 이벤트 확인 가능)

## v2.2.1 ~ v2.2.5 (소규모)
- 헤더에 수동 새로고침 버튼 추가
- 서비스워커 캐시 전략 개선 (네트워크 우선)
- Google Maps API 키 교체 (결제 활성화 키로)
- GPS 정확도 기준 미달 시 15초 후 자동 진행 (무한 대기 방지)
- 지도 탭에 실시간 비행시간 표시 추가

## v2.2.0 (중규모)
- 운항 지점 설정 기능 삭제 (반경 밖 이벤트 무시 → 알림 누락 위험 제거, 시스템 단순화)

## v2.1.0 (중규모)
- 위치확인 버튼, 헤더 GPS 버튼 삭제
- 하단 탭바로 UI 개편 (모바일 엄지 조작 최적화)
- 세이프에어리어(노치) 대응, 당겨서 새로고침 방지

## v2.0.0 (대규모)
- 익명 인증 → 이메일/비밀번호 로그인 시스템 전환
- pilot / crew 권한 분리
- GPS 세션 중복 사용 방지 (한 번에 한 명만 감지 가능)
- 헬기 마커 진행 방향 자동 전환, 저수지 라벨 숨김, Wake Lock 재요청 버그 수정

## v1.1.0 (기준점)
- 헬기 마커 색상 커스텀
- 항적(비행 경로) 24시간 자동 만료 처리
